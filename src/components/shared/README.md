# Shared Components

This directory contains reusable UI components shared across the application.

| Component | File | Description |
| --------- | ---- | ----------- |
| [AuthLayout](./AuthLayout.md) | `AuthLayout.jsx` | Layout wrapper for authentication pages (Login, Signup, etc.) |
| [Breadcrumb](./Breadcrumb.md) | `Breadcrumb.jsx` | Navigation breadcrumb for back-navigation in nested routes |
| [Button](./Button.md) | `Button.jsx` | Reusable button component with multiple variants |
| [Card](./Card.md) | `Card.jsx` | Generic card container for displaying grouped content |
| [ContactForm](./ContactForm.md) | `ContactForm.jsx` | Contact/inquiry form with validation |
| [ContactHeader](./ContactHeader.md) | `ContactHeader.jsx` | Header section for contact pages |
| [ContactInfo](./ContactInfo.md) | `ContactInfo.jsx` | Displays contact details (address, phone, email, etc.) |
| [Divider](./Divider.md) | `Divider.jsx` | Horizontal divider with optional label |
| [ErrorBoundary](./ErrorBoundary.md) | `ErrorBoundary.jsx` | React error boundary to gracefully handle component errors |
